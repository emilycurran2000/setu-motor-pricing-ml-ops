# SETU Motor Pricing MLOps Project

Project for the SETU Data Handling and Infrastructure for AI module.

## Project aim

Develop an end-to-end motor insurance risk modelling system covering data handling, model development, deployment, monitoring and model updates.

## Dataset

Public Spanish motor insurance dataset from Mendeley Data.

Coverage: 2022-2024

Raw data is not stored in this Git repository.

## Current stage

Milestone 1 — data source, evaluation strategy and storage architecture.
